--- publication note (2026-11-18)
These are the packs committed at examples/link3-handover-evidence/ in
the uibc-core repo, rebuilt with build_demo.py under the RELEASED
uibc-core 0.3.3 (the version `pip install uibc-core` gives you) and
re-verified from a clean PyPI install: the five verdicts above
reproduce exactly (PASS / PASS pinned / FAIL / PASS unpinned /
FAIL pinned). The current repo main verifier returns the same five
verdicts; its S6 line additionally labels these seals
coverage=legacy — the seal covers identity+manifest, and the
lifecycle chain is guarded by the S3 check, not by the seal. That
label is the verifier's own wording and is repeated in the folder
README rather than hidden. The original 2026-11-10 sample packs
(0.3.0-proposal build) return the same five verdicts under both
verifiers; the released-code rebuild is what is published, per the
handbook rule that public packs are built with the released code.
