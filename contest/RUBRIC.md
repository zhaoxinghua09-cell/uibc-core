# UIBC 评审规范 v0.1（rubric 加权 · 决策支持，终裁归组委会）

## 评分维度（code 赛道主 rubric）

| 维度 | 权重 | 数据来源（非评委印象分） |
|---|---|---|
| M2 事实保真 | 0.30 | verify_migration 四项校验实测结果 |
| M3 来源归因 | 0.25 | Attribution Preservation + provenance 字段完整性 |
| M4 引用保真 | 0.20 | Citation Preservation 实测 |
| M5 版本保持 | 0.15 | Version Preservation 实测 |
| 问责链完整性 | 0.10 | dispute/revocation/registry 条目可验签比例 |

分数须附证据引用（哪次 verify 的输出、哪个字段），无证据引用的打分无效。

## 等级映射

S ≥ 90 / A ≥ 80 / B ≥ 70 / C ≥ 达标线(60) / D < 60

## 评审流程（双评委 + 机器门禁）

1. 机器门禁：提交包 `verify` 必须 PASS，`gate` 不得为 DENY —— 不过者
   直接退回，不进评审。
2. 双评委独立按 rubric 打分（工具辅助计算加权，工具输出带 AIGC 标识）。
3. 分差 ≥ 10 分的维度强制合议，合议记录入档。
4. 终裁归组委会；工具结论仅为决策支持。

## 其他赛道

- **theory**：创新 0.3 / 可验证性（是否给出最小可执行示例）0.3 /
  与既有规范衔接 0.2 / 诚实边界表述 0.2。
- **design**：可落地性 0.3 / 失败模式分析完整性 0.3 / 与 uibc-core
  组件映射清晰度 0.2 / 成本可行性 0.2。

## 反作弊扣分

- 提交包验签 FAIL / gate DENY：不进入评审（门禁已拦）。
- 身份核验 high risk：冻结提交，人工核查。
- 查重疑似重复（similarity ≥ 0.85 或精确命中）：人工复核后才定论。
