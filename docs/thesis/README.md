## 写作口径（四条规定，写稿时不得违反）

1. **不主张首创，不主张更强。** 凡与他人工作相关处，只写层级差异与适用边界，不写优劣比较。
   第 2 章已明示裁决语义受 `draft-maintainer-1f916` §3.6 四值裁决启发，本文不主张首创。
2. **数字必须可重跑。** 凡写进正文的计数、延迟、覆盖率，均须在表下注明生成命令；
   作者不得手打数字。
3. **缺口写在正文。** 不使用一致性证明、不采用执行前记录、链式结构不检出等同分叉、
   第三方独立见证为零——四项均写在正文对应小节，不放附录。
4. **文献不得编造。** 参考文献 30 条均有可直达来源；取不到发布页者不入表，宁缺勿造。
