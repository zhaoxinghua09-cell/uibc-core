## 为什么选 `ietf-wg-scitt/examples`

- 这比"提一个我们的 I-D"门槛低得多，也更符合"证据先于主张"。

## 提交前必须核对的三件事（都还没做）

1. **上游 `CONTRIBUTING.md` / `README` 的格式要求**——文件名约定、是否要 JSON Schema、是否只要 `.json` 扁平列表。AAC 那次能合，不代表我们的形状合。
2. **IETF Note Well / IPR 声明**——向 IETF 仓库贡献意味着同意其 IPR 条款。这需要**你本人**以贡献者身份同意，我不能代你同意。
3. **许可证相容性**——本仓库是 **Apache-2.0**（`LICENSE` 全文为 Apache License 2.0）。IETF 代码组件惯用 BSD-3-Clause 风格；两者相容，但**向量文件应在文件头单独声明来源与许可**，不能只靠仓库根的 LICENSE。
