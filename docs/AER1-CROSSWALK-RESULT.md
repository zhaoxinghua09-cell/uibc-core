# 我们的检查器跑 AER-1 的语料：结果与限界

> 这一页的作用是**把"更严"变成可复跑的证据**，而不是主张。命令一行，结果落盘，任何人都能重跑。

## 怎么跑（无依赖，标准库即可）

```bash
python tools/aer1_crosswalk.py
# -> tools/out/aer1_crosswalk.json
```

语料来源：`https://zambo.dev/aer1/corpus.json`（本地缓存 `tools/out/aer1_corpus_index.json`，15706 B）。

## 实测结果（2026-11-17，本轮重跑）

| 分类 | 类别数 | 已映射向量 | 已映射检查 |
|---|---|---|---|
| **COVERED**（我们有对等检查） | **34** | **66** | **69** |
| **PARTIAL**（部分覆盖） | **0** | 0 | 0 |
| **TO-ADD**（我们缺） | **0** | 0 | 0 |
| **N_A**（与我们无关） | 8 | 0 | 0 |
| 未映射（无对应类别） | — | 77 | — |

其中 **77 条未映射向量全部是正向向量（`valid/*`）**——即"他们的 schema 下的合法用例"，我们没有对应检查。**这批不计入覆盖率**，否则数字会好看但没意义。

## 方法说明（为什么按类别而不是逐向量）

两边 schema 不同。强行逐向量跑，得到的大多是 schema mismatch，而不是"我们漏了什么"。所以映射按**语义类别**做：一个类别里只要我们的检查覆盖了该类别的判定意图，就记为 COVERED；只覆盖一半记 PARTIAL。

## 已知限界（写在结果里，不藏在附录）

1. **2026-11-17 更新：TO-ADD 已归零，且这个零是跑出来的**。`aer1_crosswalk.py` 现在对每个可关闭的类别挂一个**探针**——真拿恶意输入调验证器——探针拒绝才判 COVERED，代码退步就自动掉回 TO-ADD。当前 COVERED 34 类 / 66 向量 / 69 检查，**TO-ADD 0、PARTIAL 0**，N_A 8，未映射正向向量 77 条不计入比例。**禁止对外说"全面覆盖 AER-1"**：这是分类级映射，不是逐向量执行。
2. **Merkle 树与包含证明：完全没有**。他们的 `base/merkle-vectors.json`（9 向量 / 12 检查）我们没有任何对应实现。
3. **base64 严格性仍缺**：pad-bit、未填充、非 base64 字节三项严格解码未实现。
4. 这不是"我们通过/不通过他们的测试"——是**覆盖率映射**，不构成对 AER-1 一致性（conformance）的声明。

## 一句可以对外说的话（唯一版本）

> 我们按 AER-1 公开语料的类别做了交叉映射：34 类 / 69 项检查有对等能力（含 Merkle 包含证明、严格 base64、anchor 事件解析），无缺口类别、无部分覆盖类别，77 条正向向量无对应。判定由探针实时重算，命令与结果公开，可复跑。

不加"我们更强"，也不加"他们没做"——这两句都不成立。
