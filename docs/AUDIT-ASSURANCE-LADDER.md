# 审计保证阶梯（AIA-0 … AIA-4）

2026-11-24 建。对标 DIF KYA-OS 的 `AAP-0…AAP-4`——他们有审计保证档，我们没有；这一页就是把档补上，并且**先给自己打分**。

规则：**自评，不是认证。** 每一档只问"有没有能被人对账的东西"，不问"我们做得用不用心"。

---

## 五档定义

| 档 | 要求 | 可对账物 |
|---|---|---|
| **AIA-0** | 有可执行判定，别人能跑出同一个判词 | 一条命令 + 判词 |
| **AIA-1** | 判定有证据前置（无证据不判通过），且篡改能被抓、反假阳性不被误判 | 红队套件 + 对照用例 |
| **AIA-2** | 有第二实现且与主实现逐条对齐；生成物与代码**逐字节**绑定，防漂移 | 第二实现 + 字节 pin + 漂移测试 |
| **AIA-3** | 有**项目外**的人在自己机器上跑出结果并回传，我方能在指定 commit 上复算对上 | 外部节点登记 + 回传件 sha256 |
| **AIA-4** | 有**与本项目无关**者的独立复现，且有组织级采纳或外部文档引用 | 无关复现 + 采纳记录 |

---

## 我们的自评（逐档给证据，不给形容词）

| 档 | 判定 | 依据（可点） |
|---|---|---|
| AIA-0 | **满足** | `python3 tools/outsider_audit.py` 一条命令出判词，退出码 0/1 有语义 |
| AIA-1 | **满足** | 基线必须为 `INCONCLUSIVE`（否则等于"没签名也算签了"）；11 条篡改全抓；2 条对照不误判；`evidence=[]` 时 `VERIFIED` 直接抛 `ResultError` |
| AIA-2 | **满足** | `tools/verify-js/verify.mjs` 第二实现 + `tools/assert_second_impl.py` 强制同步 + CI job `second-implementation`；`schemas/verification-result.schema.json` 与代码逐字节比对；语义冻结双哈希 |
| AIA-3 | **部分** | `docs/EXTERNAL-NODES.md` 2 条：001 为同工作组通信方（第三方执行、非第三方利益）；002 的 `independent=PASS` 已被本人要求加注——**该 run 不构成独立评估证据**（PR #356 之前的入口缺陷）。故"有回传、可复算"成立，"无利害"不成立 |
| AIA-4 | **未达** | 外部文档引用 0、团体采纳 0、与本项目无关者独立复现 0 |

**当前档位：AIA-2（含 AIA-3 的两条受限记录，不计入）。**

---

## 为什么这样打分而不是给自己 3

- AIA-3 的字面要求是"项目外的人跑过"，2 条确实满足字面；但两条都是**我们冷启动邀请**的，001 自述是第三方执行非第三方利益，002 的关键字段被本人要求加注为"不构成独立评估证据"。若把它们算作 AIA-3，就等于把"被我们请来的人跑过"说成"独立验证"——这正是我们批判别家的那件事。
- 所以 AIA-3 挂在两件事上：一次**主动到访**的陌生运行，或一次**无利害方**（例如另一家规范的维护者在不知道自己会被引用的情况下跑）。任一发生即升档。

---

## 升档需要的动作（都对外部条件有依赖）

| 目标档 | 需要什么 | 谁必须出手 |
|---|---|---|
| AIA-3 | 一位与项目无关的开发者主动跑 `tools/outsider_audit.py` 并回传 `--json` 输出 | 外部个人；我方只提供三分钟路径与登记规则 |
| AIA-4 | 至少一家组织采纳，或一份非我方撰写的文档引用本仓作为判定/证据层参照 | 外部组织 |

**这两档都不可能靠内部努力补上。** 这是当前唯一真正的瓶颈，也是为什么 P1 的第一件事应当是"把三分钟路径变得比反对意见更便宜"，而不是再加一个模块。

## 与竞品的档位对照（只比可对账的部分）

| 对手 | 最接近的档 | 差别 |
|---|---|---|
| KYA-OS | AAP-0…AAP-4（自家定义） | 他们有档位定义与每档测试条目；我们有档位但没有第三方认证方 |
| AuthZEN | 官方符合性计划（6 plan） | 他们由基金会发证；我们只能自评 |
| SCITT | RFC 9943 + 多 profile | 他们有权级文件；我们只有自建套件 |
| 信通院 | 四地节点开放接入 | 他们有基础设施；我们有判定语义 |

**一句话**：我们能把"档"说清楚，但**发证权不在我们手里**——所以这页的作用是自评与对账，不是宣称合规。
