## What the numbers say

- **36 attacks, 34 of which caught something.**
- **32 attacks isolate exactly one check** (fan-out 1): flip one byte in evidence, truncate one evidence file, delete one evidence file, edit the evidence root, add an undeclared file, duplicate a JSON member name, mismatch agent identity, drop the tail entry and file ….
- **Checks never reached by any attack: none.**

Fan-out above 1 is not a defect; a single edit can genuinely break several facts at once (a deleted file breaks its hash, its inclusion proof and its declared count). It is recorded so a claim of 「each check tests one thing」 cannot be made loosely.
