MISSING-KEY WORKED EXAMPLE - RUN TRANSCRIPT
===========================================
Environment: Python 3.12.3, uibc-core 0.3.3 from PyPI
  python3 -m venv venv && venv/bin/pip install uibc-core==0.3.3
  (every command below is the released CLI: venv/bin/uibc ...)
First run: 2026-11-18. Verify outputs are deterministic: the report
carries no timestamp, so re-running the verify section reproduces
the shipped report-*.json files byte for byte.

-------------------------------------------------------------------
PART 1 - BUILD THE SEALED PACKAGE (in scratch dir rebuild/)
-------------------------------------------------------------------
$ # Demo keys are fixed and published so the example is reproducible.
$ # They are derived from stated strings (sha256 hex) - DEMO ONLY.
$ python3 -c "...sha256(b\"uibc demo owner key - joe example 2026-11-18\")..." > keys/demo-owner.key
$ python3 -c "...sha256(b\"uibc WRONG key - joe example 2026-11-18\")..." > keys/wrong.key
$ cat keys/demo-owner.key
08b56deb66b812126d37883769a1b7bf8dbbf1d3860cd3509de6a0cf9a457490
$ cat keys/wrong.key
659eb2e4fe95d48386a65e2352de422855851f2fe41c4e34beccdf63c5968648
$ uibc init rebuild
