# UIBC-Next 执行板（P0 / P1 / P2）

2026-11-24 建。用途：把十根支柱压成一张能按天推进的表，每一行都指向**可验收的证据**，而不是"已完成"三个字。

度量口径先钉死（与 Success Criteria 一致）：**只认独立复现、外部实现、外部运行记录、真实集成与采纳**。仓库数、功能数、自报兼容**不计分**。

## 治理（与本轮一致）

- 不合并主分支、不对外提交、不发信、不发布，均需明确批准；
- 本轮所做的：新增 3 份文档 + 1 个测试 + 1 处打包修复，全部在分支上，未触碰 `main`；
- 所有陈述区分四档：**已核验事实 / 自报声明 / 独立证据 / 未验证假设**——本页每行属于哪一档，由"验收"列决定，不由措辞决定。
