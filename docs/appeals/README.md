# Appeals

Records of `APPEAL:` issues that reached a written decision live here.

Naming: `<YYYY-MM-DD>-<item-id>.md`

Each file must contain:

1. the item id and version the appeal was about;
2. the disputed check (e.g. `C3`), quoted;
3. the evidence the appellant supplied, with sha256;
4. the re-run log sha256;
5. the decision: upheld / corrected / withdrawn;
6. the rationale, and who decided;
7. if a correction or withdrawal: the previous verdict, kept verbatim, not overwritten.

The process itself is in [`APPEALS.md`](../APPEALS.md).
Appellants are anonymised in these records; the issue thread stays public.
