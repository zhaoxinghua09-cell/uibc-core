二、本机真跑：三家装上之后发生了什么

不是读文档。在 Windows + Python 3.13 上真实安装并执行；失败的照实写，不做产品评价。

包装到的版本跑了什么结果
novafabric0.108.0 nova capture 三次（含 --runner local --no-daemon）、seal init、verify、inspect 路径未跑通 每次都触发它自己的完整性守卫："the capsule directory was replaced while the workload ran … must not be trusted"；seal init 建了身份但 capsule 仍无 .seal/，verify 拒绝；inspect 报 asset not found。我们没有去调试它的代码。

aiauditlog模块 ai_audit_log0.2.0b1 import、AuditRecorder、EventBuilder.create、ChainVerifier 装得上，端到端未成立 嵌套 pydantic 模型（Source/Actor/Outcome(status=, code=)），冒烟脚本每次卡在模型校验；ChainVerifier 存在。记"未成立"，不记成它的失败。

这一格的分量：矩阵里第一次出现"竞品的可执行声明在它的主场之外跑不通"。写它必须和对我们自己的 Rekor 失败一样——带复现的观察，不是对设计下判决。

三、三个必须改口的判断

不是我们独有

"外人能复跑"已是入场券

Tracekit 已交付 Python 与 TypeScript 两个验证器（同一作者所写，TypeScript 版是单页浏览器），并自报 63 个包结论一致、33 个伪造全部拒绝——这是作者自报，不是第三方复现。它比我们已做的更强。

我们仍独有的

公开一个"验不过"的结果

我们的 Rekor 包含证明验不过，自写 RFC 6962 走法失败，第三方 rekor_log_verifier 用另一个根也失败。上表没有一家公开这种负面结果——他们只报通过的实验数。

最便宜的一步

语言中立一致性语料

agent-receipts 用 8 条向量做到"任何合规实现产出逐字节相同的签名"。我们只有 Python 测试。一份向量文件即可把"我们有测试"升级为"任何人不用我们的代码就能验我们"。

"全面超越"在这里的正确含义：不可能意味着"别人都没有"。六个项目已发布或可安装。可做到的是三条—— ①六个维度上我们不沉默，落后就同句承认； ②一个维度用证据领先：公开负面结果 + 复现命令； ③一个维度从"声称"升级为"已演示"：第二实现或语言中立语料。
