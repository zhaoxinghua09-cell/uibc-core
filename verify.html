Verify a UIBC evidence package — in your browser

The same S1–S6 checks and the same three-valued verdict as uibc verify (v0.3.0): PASS, FAIL, or an honest INCONCLUSIVE. Everything runs locally on this page — nothing is uploaded.

与命令行 uibc verify（v0.3.0）同一套 S1–S6 检查、同一个三值裁决：PASS、FAIL，或诚实的 INCONCLUSIVE。全部在本页本地运行，不上传任何数据。

Honest limits · 诚实边界 — This page is a JavaScript port of the Python reference verifier; on the published fixture corpus its verdicts agree check-for-check with uibc verify. HMAC seals (v0.2) can only be checked with the owner key; without one they are INCONCLUSIVE, never silently passed. Ed25519 seals (v0.3) are verified publicly. Timestamps are not independently anchored. JSON numbers are formatted the JavaScript way; a package whose sealed JSON contains non-integer numbers may hash differently from the Python verifier. 本页是 Python 参考验证器的 JavaScript 移植版，在已发布夹具集上与 uibc verify 逐项一致。HMAC 封签（v0.2）无所有者密钥时只能判 INCONCLUSIVE，绝不放行；Ed25519 封签（v0.3）可公开验证。时间戳未做独立锚定。
